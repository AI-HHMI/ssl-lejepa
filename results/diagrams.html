Models

MAE: encode a quarter of the tokens, decode the rest to voxels

flowchart TB
    DL["miao loader"] -->|"vol: Batch C Z Y X"| VM["ViewMaker"]
    VM -->|"view: Batch C Z Y X"| ENC["ViT3DEncoder<br/>forward_features(keep)"]
    VM -->|"view: Batch C Z Y X"| PAT["patchify<br/>gather hidden"]
    ORD["random order<br/>mask_ratio 0.75"] -->|"keep: Batch Nvis"| ENC
    ORD -->|"order: Batch N"| DEC["decoder<br/>mask tokens + sincos<br/>2 TransformerBlocks"]
    ORD -->|"hidden: Batch M"| PAT
    ENC -->|"latent: Batch Nvis D"| DEC
    DEC -->|"pred: Batch M Vox"| MSE["MSE"]
    PAT -->|"patches: Batch M Vox"| NP["norm_pix"]
    NP -->|"target: Batch M Vox"| MSE
    MSE -->|"loss: scalar"| OPT["backward<br/>AdamW"]

Masked tokens: predict a hidden cube of a shifted view

flowchart TB
    DL["miao loader"] -->|"vol: Batch C Z Y X"| VM["ViewMaker"]
    VM -->|"region: Batch C Z+s Y+s X+s"| CR["crop x 2<br/>random origins"]
    CR -->|"view: Batch C Z Y X"| ENC["ViT3DEncoder<br/>forward_features(keep)"]
    CR -->|"target_view: Batch C Z Y X"| ENC2["ViT3DEncoder<br/>(same weights)"]
    CR -->|"offset: Batch 3"| MB["mask_block"]
    MB -->|"visible: Batch Nvis"| ENC
    MB -->|"masked, masked_coords: Batch M"| PRED
    ENC -->|"context: Batch Nvis D"| PRED["Predictor<br/>mask tokens + sincos<br/>4 TransformerBlocks"]
    PRED -->|"hidden: Batch M D"| PJ["projector MLP"]
    ENC2 -->|"tokens: Batch N D"| PJ2["projector MLP<br/>(same weights)"]
    PJ -->|"pred: Batch M Dproj"| LOSS["lejepa_loss<br/>error + lamb x SIGReg"]
    PJ2 -->|"emb: Batch N Dproj"| G["gather masked"]
    G -->|"target: Batch M Dproj"| LOSS
    PJ2 -->|"emb: Batch N Dproj"| SG["sigreg_term"]
    SG -->|"sig: scalar"| LOSS
    MB -->|"masked: Batch M"| G
    LOSS -->|"loss: scalar"| OPT["backward<br/>AdamW"]
